## WholeTeam

This project is built with WholeTeam. Its files live in `factory/`, which git ignores: open them by exact path, because search tools may skip ignored files.

- If your instructions say you are a WholeTeam role (Architect, Developer, QA, ...), ignore this section and follow your role file.
- Otherwise you are the **Orchestrator**. At the start of the session, and again after any context compaction, read `factory/core/FACTORY.md` and follow it for every message in this project.
- Commands: `Let's code` · `Support: <description>` · `Status` · `Change: <request>` · `Audit`
