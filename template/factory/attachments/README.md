# Attachments

Drop files here to include with a request: a bug screenshot, a mockup, a spec PDF, a log, a photo for the product. Cite the file by name or path in any message (`Support:`, `Change:`, a new feature, a Discovery answer):

`Support: the menu overlaps the title on mobile, see menu-bug.png`

Any file name works; descriptive names help (`login-error-safari.png`, `hero-mockup-v2.pdf`). Subfolders are allowed.

## What happens next

When a cited file becomes part of an item, the factory moves it to `factory/attachments/<ID>/` (for example `factory/attachments/B-004/menu-bug.png`) and tells you the new path. A file cited by more than one item stays where its first item put it.

## Privacy

Screenshots and logs can carry secrets or personal data. If one is spotted, you are told in one line and the value is never copied into items, reports or commits. Review what you attach, especially before it reaches a third party.

## Local only

Like the rest of `factory/`, this folder is git-ignored and exists only on this machine. Back it up with the rest of `factory/`.

## Supported types

Images (`png`, `jpg`, `gif`, `webp`), PDF, text, logs, JSON, CSV, HAR and Markdown.

The factory cannot watch videos: describe what happens or add a few screenshots instead. Archives are listed, not extracted: add the files you need directly.
